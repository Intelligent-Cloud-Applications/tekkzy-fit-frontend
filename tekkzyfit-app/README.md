# Tekkzy Fit app

Expo Android check app. Two screens only: connect the face machine on gym Wi-Fi, and fetch cloud members.

## Run

```bash
cd tekkzyfit-app
npm install
npx expo start
```

Open it on an Android phone or tablet that is on the **same Wi-Fi** as the face machine. Expo Go is enough for this check.

1. **Connect device** — type the machine IP and tap Connect, or tap Scan Wi-Fi.
2. **Fetch members** — loads production members for Fitnessworld001.

The face machine must be on its home screen, not the Wi-Fi search list.
